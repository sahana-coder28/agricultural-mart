## Changes Made According To This Project

- Replaced React.js, Node.js, Express.js and MongoDB sections with Python, Flask, Jinja2, SQLite and SQLAlchemy.
- Added Razorpay because the project includes checkout, payment creation, payment verification and payment history.
- Added Gemini API Chatbot because the project contains the AgroBot assistant for product help, order context and agricultural guidance.
- Added separate module descriptions for customer, farmer and admin workflows.
- Added database tables based on the actual models: User, Product, Review, CartItem, WishlistItem, Order, OrderItem, Admin, Message and Payment.
- Added admin-side modules for dashboard, product management, users, messages, orders and transactions.
- Added farmer-side product management because farmers can add, edit and delete their own products.
- Updated the report flow so System Design appears before detailed module explanation and coding.
